# ApexBuffer v1.6.0

Smart adaptive input buffer for Geometry Dash (Geode).

## Buttons (Geode official pattern)
- Main menu: adds to `bottom-menu` + `updateLayout()`
- Pause menu: adds to `right-button-menu` / `left-button-menu` + `updateLayout()`
- Requires **geode.node-ids**

## Build
Push to main or run workflow **Build ApexBuffer**, download artifact, install `.geode`.
Also install **Node IDs** from Geode if missing.

## Check log
- `ApexBuffer v1.6.0 loaded`
- `MenuLayer::init hooked`
- `main menu button added to bottom-menu`
